# Architecture

**Blockside MCP is an unofficial companion project for Minecraft.** It has no approval from or association with Mojang or Microsoft.

## Repository map

The repository contains the Core governance baseline for Blockside MCP.

- Repository instructions define the workflow and route contributor and agent tasks. [AGENTS.md](../AGENTS.md)
- Local governance scripts verify documentation links, specs, decision records, postmortems, and seed ownership. [Gate runner](../scripts/run-gates.mjs)
- The Repo Seed manifest records which capabilities are enabled and which files they manage. [Manifest](../.repo-seed/manifest.json)

## Structural changes

Update this map when the repository gains an implementation boundary. Follow the repository workflow for changes that cross a risk boundary or establish a durable design choice. [Governance loop](../AGENTS.md#governance-loop-hard-rules)
